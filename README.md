# Yandex Disk Sync for Obsidian

Полноценный, безопасный и отказоустойчивый плагин двусторонней синхронизации заметок Obsidian между **Windows** и **Android** через официальный REST API Яндекс Диска.

---

## Ключевые возможности и преимущества

1. **Строгая изоляция и безопасность (Принцип наименьших привилегий):**
   * Плагин запрашивает доступ **только к изолированной системной папке** `cloud_api:disk.app_folder` (`диск:/Приложения/ObsidianSync/`).
   * Плагин физически не имеет доступа к вашим личным фотографиям, документам и остальным файлам на Яндекс Диске.
   * Полная защита от атак Directory Traversal и URL-encoded манипуляций с путями.

2. **Гарантия сохранности данных (Zero Data Loss):**
   * **3-Way Sync Engine:** Отслеживание изменений через локальный манифест состояний (`sync-manifest.json`) по криптографическим хешам SHA-256 и ETag, а не по системному времени `mtime`. Полный иммунитет к рассинхронизации часов между Windows и Android.
   * **Ветки конфликтов:** При одновременном редактировании одной заметки на ПК и телефоне локальный файл **никогда не затирается**. Создается файл конфликта `Имя.conflict-ГГГГММДД-ЧЧММСС.md` с сохранением обеих версий и уведомлением пользователя.
   * **Атомарные операции:** Скачивание и запись происходят во временные буферы с последующей атомарной подменой, что исключает повреждение заметок при внезапном разрыве связи.
   * **Умные удаления (Tombstones):** Защита от воскрешения удаленных файлов с автоматической очисткой устаревших меток через 30 дней.

3. **Сквозное шифрование (E2EE — по желанию):**
   * Локальное шифрование заметок и вложений по стандарту **AES-256-GCM** через нативный Web Crypto API перед отправкой в облако.
   * Генерация криптографических ключей по стандарту **PBKDF2** (100 000 итераций SHA-256 со случайной 16-байтной солью).
   * Защита заголовка от подделки (Authenticated Additional Data — AAD).

4. **Кроссплатформенность без системных зависимостей:**
   * Сборка плагина содержит **0 зависимостей от Node.js `fs`**, использует только встроенные интерфейсы `obsidian.requestUrl` и `Vault API`, благодаря чему работает быстро и стабильно на **Android** и **Windows**.
   * Автоматическая фильтрация служебных файлов интерфейса (`workspace.json`, `workspace-mobile.json`, `.trash`), предотвращающая поломку интерфейса смартфона разметкой от ПК-монитора.
   * Поддержка любых бинарных вложений (изображения PNG/JPG, PDF-документы, аудиозаписи).

## 1. Как получить OAuth-токен в Яндексе (2 минуты)

1. Перейдите на портал разработчика Яндекса: [oauth.yandex.ru/client/new](https://oauth.yandex.ru/client/new).
2. Заполните поля:
   * **Название приложения:** `Obsidian Sync`
   * **Платформы:** выберите **Веб-сервисы**.
   * **Redirect URI:** укажите `https://oauth.yandex.ru/verification_code`
3. В разделе **Данные (Доступы)** найдите **Яндекс Диск REST API** и отметьте **ТОЛЬКО ОДИН пункт**:
   * ✅ **Доступ к папке приложения на Диске (`cloud_api:disk.app_folder`)**
   *(Не отмечайте полный доступ ко всему Диску — приложению нужна только своя изолированная папка).*
4. Нажмите **Создать приложение**.
5. Скопируйте полученный **Client ID** приложения.
6. Вставьте ваш `Client ID` в следующую ссылку и откройте ее в браузере:
   ```text
   https://oauth.yandex.ru/authorize?response_type=token&client_id=ВАШ_CLIENT_ID
   ```
7. Нажмите **Разрешить**, и Яндекс покажет ваш готовый OAuth-токен (вида `y0_...`). Скопируйте его.

## 2. Установка плагина

### На компьютере (Windows):
1. Откройте папку вашего хранилища в Проводнике.
2. Перейдите в папку `.obsidian/plugins/` (если папки `.obsidian` не видно — включите показ скрытых файлов в Проводнике).
3. Создайте новую папку с именем `yandex-disk-sync`.
4. Скопируйте в нее 3 файла из папки проекта:
   * `main.js`
   * `manifest.json`
   * `styles.css`
5. В Obsidian откройте **Настройки → Сторонние плагины (Community plugins)**, нажмите кнопку обновления списка плагинов и включите тумблер напротив **Yandex Disk Sync**.
6. В настройках плагина вставьте ваш OAuth-токен и нажмите **Test Connection** (должно появиться зеленое сообщение с вашим логином и свободным местом).

### На смартфоне (Android):
1. Скопируйте ту же папку `yandex-disk-sync` (с теми же тремя файлами) в память телефона в папку вашего хранилища:
   `Внутренняя память/Documents/ИмяВашегоХранилища/.obsidian/plugins/yandex-disk-sync`
   *(Для копирования удобно использовать любой файловый менеджер на Android, например Total Commander, Solid Explorer или штатный проводник при подключении телефона по USB к ПК).*
2. Откройте Obsidian на телефоне, перейдите в **Settings → Community plugins**, обновите список и включите **Yandex Disk Sync**.
3. Вставьте в настройки тот же OAuth-токен.
4. Нажмите иконку синхронизации в боковом меню!

## 3. Режимы работы и настройки

* **Синхронизация при запуске (Sync on Startup):** автоматически сверяет и скачивает/выгружает заметки через 3 секунды после открытия Obsidian.
* **Периодическая синхронизация (Periodic Sync):** фоновый опрос изменений каждые 5, 10, 15, 30 или 60 минут (0 — только вручную).
* **Ручной запуск:** 
  * Клик по иконке со стрелками в левой боковой панели (Ribbon Icon);
  * Клик по индикатору статуса в правом нижнем углу окна (Status Bar);
  * Через палитру команд (`Ctrl+P` → *Yandex Disk Sync: Synchronize with Yandex Disk now*).
* **Сквозное шифрование (E2EE):** если вы хотите зашифровать все файлы на Яндекс Диске, включите тумблер *Enable Client-Side Encryption* и задайте надежный мастер-пароль. **Важно:** на всех устройствах (ПК и телефон) должен быть введен строго один и тот же мастер-пароль!
